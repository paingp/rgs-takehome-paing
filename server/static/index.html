Symbol Spotter

Selection

Turn on Select symbol, then drag a rough box around a door, a marker or a receptacle. The box does not need to be tidy. The tool measures what you enclosed to decide how to find the rest — a curve is swept for, a shape is matched.

Candidates shows every blob of ink the detector can see at all — the connected pieces left after walls, grid lines and borders are stripped out. Nothing here is matched or judged. It is the difference between “the detector never saw it” and “the detector saw it and scored it low”, which need opposite fixes. A symbol with no amber box around it was lost before scoring began.
