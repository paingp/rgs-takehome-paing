Symbol Spotter

Selection

Turn on Select symbol, then drag a rough box around a door, a marker or a receptacle. The box does not need to be tidy. The tool measures what you enclosed to decide how to find the rest — a curve is swept for, a shape is matched.

Candidates shows every blob of ink the detector can see at all — the connected pieces left after walls, grid lines and borders are stripped out. Nothing here is matched or judged. It is the difference between “the detector never saw it” and “the detector saw it and scored it low”, which need opposite fixes. A symbol with no amber box around it was lost before scoring began.

      Ground truth

        Drag a box around the missed symbol. Esc cancels.

        Reset hides the recorded boxes along with clearing the count; it never removes them. Clear annotations is the button that does — undoably, and without touching the saved file, which stands until you save again. G shows the recorded boxes, one colour per class; E edits them. Click one to select it, drag a handle to resize, change its class or occlusion above, Del to remove it. The detection’s own box never moves — what this corrects is the annotation, and the harness grades against that.

        Accepting a hit with A records it as real. M arms “+ Missed” — drag a box, pick the class and whether anything crosses it, confirm — which is the half no accept/reject can produce. O marks an instance occluded: a wall, note or dimension crosses it. That is the axis graded separately, and it is set by eye rather than inferred from whether the tool found it. S saves.

        Grading

          V draws the last run of python -m eval.suites --page N: green found it, orange-red got it wrong or lost it, amber sent it to review. Click any row to fly to the ink. This is read from eval/reports/ rather than graded live — a run costs a full detection pass, and the tool should not have two places where one happens.

          Two symbol classes are registered. The margin gate fires only where they claim the same ink — which happens where a marker is found inside a blob it was fused to. The nested-symbol case it was built for, duplex inside quad, is still untested.
