      Ground truth

      Counted on the generic thresholds until it has ground truth of its own.
          Drag a box around the missed symbol, then Enter to record it. Stays armed, so the next drag starts the next instance. Esc stops.

          G show · E edit · M record a missed one · O occluded · Del remove · S save

          + Missed is the half no accept or reject can produce: drag, Enter, drag, Enter — it stays armed until Esc. Editing corrects the annotation, never the detection’s own box, because the annotation is what grading measures against.

          Occluded means a wall, note or dimension crosses the symbol. It is set by eye rather than inferred from whether the tool found it, and it is graded as its own number.

          Reset only hides these boxes. Clear annotations removes them — undoably, and the saved file stands until you save again.

          Evaluation

              Scores this page's count against its annotations, once every match has been accepted or rejected. What you accepted is what the tool found — whichever band it came from — and what you rejected is a false positive. Click a missed row to fly to the ink.
